Раздел 1: Разность квадратов

Разность квадратов — это самая популярная формула для сокращения дробей. Она позволяет разложить выражение на две скобки (с минусом и с плюсом).

a2 - b2 = (a - b)(a + b)

Когда мы видим эту формулу в числителе или знаменателе дроби, мы раскладываем её на множители, чтобы найти одинаковую скобку и сократить её!

10 решенных примеров (от простого к сложному):

  1. x2 - 25 = x2 - 52 = (x - 5)(x + 5)
  2. 9y2 - 16 = (3y)2 - 42 = (3y - 4)(3y + 4)
  3. 100 - a2b2 = (10 - ab)(10 + ab)
  4. x2 - 9x - 3 = (x - 3)(x + 3)x - 3 = x + 3
  5. 4a2 - 12a + 1 = (2a - 1)(2a + 1)2a + 1 = 2a - 1
  6. 25 - y2y - 5 = (5 - y)(5 + y)-(5 - y) = -(5 + y) = -5 - y (Внимание на вынос минуса!)
  7. a4 - b4a2 + b2 = (a2 - b2)(a2 + b2)a2 + b2 = a2 - b2
  8. x2 - 0.04x + 0.2 = (x - 0.2)(x + 0.2)x + 0.2 = x - 0.2
  9. x - yx2 - y2 = x - y(x - y)(x + y) = 1x + y
  10. 36m2 - 49n26m - 7n = (6m - 7n)(6m + 7n)6m - 7n = 6m + 7n

Раздел 2: Квадрат суммы

Квадрат суммы позволяет "свернуть" длинный трехчлен обратно в скобку в квадрате. Это невероятно полезно, когда весь числитель или знаменатель выглядит как большая формула.

a2 + 2ab + b2 = (a + b)2

Главное — найти квадраты по краям (a2 и b2) и проверить, что посередине стоит их удвоенное произведение (2ab).

10 решенных примеров (от простого к сложному):

  1. x2 + 6x + 9 = x2 + 2·x·3 + 32 = (x + 3)2
  2. 4a2 + 12a + 9 = (2a)2 + 2·2a·3 + 32 = (2a + 3)2
  3. 25 + 10y + y2 = (5 + y)2
  4. x2 + 8x + 16x + 4 = (x + 4)2x + 4 = x + 4
  5. 9a2 + 6a + 13a + 1 = (3a + 1)23a + 1 = 3a + 1
  6. a2 + 2ab + b2a2 - b2 = (a + b)2(a - b)(a + b) = a + ba - b
  7. x + 1x2 + 2x + 1 = x + 1(x + 1)2 = 1x + 1
  8. 16x2 + 24x + 94x + 3 = (4x + 3)24x + 3 = 4x + 3
  9. 100m2 + 20mn + n210m + n = (10m + n)210m + n = 10m + n
  10. x4 + 2x2y + y2x2 + y = (x2 + y)2x2 + y = x2 + y

Раздел 3: Квадрат разности

Квадрат разности работает точно так же, как квадрат суммы, только перед удвоенным произведением стоит знак минус.

a2 - 2ab + b2 = (a - b)2

Важное правило: (a - b)2 абсолютно равно (b - a)2. Поэтому при сокращении дробей мы можем легко менять их местами внутри квадрата без вынесения минуса!

10 решенных примеров (от простого к сложному):

  1. y2 - 10y + 25 = (y - 5)2
  2. 16x2 - 8x + 1 = (4x - 1)2
  3. p2 - 14p + 49 = (p - 7)2
  4. x2 - 12x + 36x - 6 = (x - 6)2x - 6 = x - 6
  5. 9a2 - 12a + 43a - 2 = (3a - 2)23a - 2 = 3a - 2
  6. a2 - 2ab + b2b - a = (b - a)2b - a = b - a (Применили правило смены мест в квадрате)
  7. x2 - 4x + 4x2 - 4 = (x - 2)2(x - 2)(x + 2) = x - 2x + 2
  8. 4 - 4x + x2x - 2 = (2 - x)2x - 2 = (x - 2)2x - 2 = x - 2
  9. 36 - 12m + m26 - m = (6 - m)26 - m = 6 - m
  10. x2 - 20x + 1002x - 20 = (x - 10)22(x - 10) = x - 102

Раздел 4: Сумма и разность кубов

Сумма и разность кубов раскладываются на две скобки: "маленькую" (без степеней) и "большую" (неполный квадрат, где удвоенное произведение становится просто произведением с обратным знаком).

a3 - b3 = (a - b)(a2 + ab + b2) a3 + b3 = (a + b)(a2 - ab + b2)

Эти формулы часто встречаются в сложных дробях, где одна из скобок полностью сокращается со знаменателем или числителем.

10 решенных примеров (от простого к сложному):

  1. x3 - 8 = x3 - 23 = (x - 2)(x2 + 2x + 4)
  2. y3 + 27 = y3 + 33 = (y + 3)(y2 - 3y + 9)
  3. x3 - 1x - 1 = (x - 1)(x2 + x + 1)x - 1 = x2 + x + 1
  4. a3 + b3a + b = a2 - ab + b2
  5. 8m3 - n32m - n = (2m - n)(4m2 + 2mn + n2)2m - n = 4m2 + 2mn + n2
  6. x3 + 64x2 - 4x + 16 = (x + 4)(x2 - 4x + 16)x2 - 4x + 16 = x + 4
  7. 125 - y325 + 5y + y2 = (5 - y)(25 + 5y + y2)25 + 5y + y2 = 5 - y
  8. x3 - y3x2 - y2 = (x - y)(x2 + xy + y2)(x - y)(x + y) = x2 + xy + y2x + y
  9. 27a3 + 13a + 1 = (3a + 1)(9a2 - 3a + 1)3a + 1 = 9a2 - 3a + 1
  10. p3 - 1000p2 + 10p + 100 = (p - 10)(p2 + 10p + 100)p2 + 10p + 100 = p - 10
